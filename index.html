Tennis Ball Tracker — OpenCV
↗

Real-time tennis ball tracking application using OpenCV trackers and HSV color segmentation. Implements a full image processing pipeline — Gaussian filter, BGR→HSV conversion, binary mask thresholding, morphological cleaning (erosion + dilation), contour extraction and bounding box. Compares two tracking methods: manual ROI selection (CSRT) and fully automatic HSV color detection. 3-panel Tkinter interface showing original video, CSRT tracking and HSV mask simultaneously.
